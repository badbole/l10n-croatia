KPD Classification
==================

Implemented based on:
    * Klasus - https://web.dzs.hr/App/klasus/

#### How to prepare .xml data for importing in Odoo?
- Prepare the .csv file with name kpd_classification.csv
- The .csv file has to be formatted in the same way as kpd_classification.csv is formatted
  (it is important to keep parent-child order of data!)
- Run the convert_kpd.py file and choose the type of the output file (csv or xml)
